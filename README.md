# CITRA SERUPA

Sistem rekomendasi gambar berbasis kemiripan visual (*visual similarity*) menggunakan Machine Learning / Deep Learning.

## 🎯 Tujuan Proyek
Mengembangkan sistem yang mampu menerima input berupa sebuah citra/gambar dan merekomendasikan gambar-gambar serupa dari koleksi data berdasarkan ekstraksi fitur visual dan perhitungan jarak kemiripan (*similarity metric*).
